# Bounded Plan Writing

Write small vertical behavior slices with exact contracts, dependencies,
acceptance, test seams, verification commands, and likely repository surfaces.
For multiple tasks, hand the result to `to-tickets` and `parallel_planner` so
they can add write sets, shared surfaces, resources, worktrees, and waves.

Return the plan to `agent-team-dev`. Do not invoke another execution skill,
spawn writable agents, implement tasks, review code, or finish a branch.
