# Handoff template

```markdown
# Handoff: <short focus>

Generated: <ISO-8601 timestamp>
Next-session focus: <what the next session is for>

## Resume authority

- QTeam run: <run-id or none>
- Goal checkpoint: <digest or none>
- Durable phase / next action: <fresh status result or standalone next action>
- Git: <repository, branch, HEAD, bounded dirty-state summary>

## Objective and constraints

<one paragraph; include only constraints that change the work>

## Current state

- Done: <facts with artifact/commit links>
- In progress: <one bounded item>
- Not started: <only immediate downstream work>

## Decisions and blockers

- <unresolved user decision, dependency, typed handoff, or external wait>

## Evidence and artifacts

- Spec/plan/ADR/issues: <paths or URLs>
- Implementation/diff: <commit or bounded paths>
- Verification/reviews: <commands, receipts, last known result>

## Exact next action

1. <first command or inspection>
2. <condition that decides the following action>

## Suggested skills

- `$<installed-skill>` — <why the next session needs it>
```

Do not add raw secrets, transcript excerpts, entire diffs, or copied documents.
