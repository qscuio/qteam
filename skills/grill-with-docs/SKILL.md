Invoke `grilling` and `domain-modeling` together. Capture each resolved term in
the relevant `CONTEXT.md` as it crystallizes. Offer an ADR only when the choice
is hard to reverse, surprising without context, and a real trade-off. Return
resolved decisions to QTeam; do not begin implementation.
